# لو زهقت في الشغل ادخل هنا

موقع ألعاب ومعلومات للناس الزهقانة في الشغل: 5 ألعاب سريعة، 6 أقسام معلومات باختبارات، تحدي يومي واحد لكل الناس، كارت شير «مذكرة داخلية» بالسكور، لينكات تحدي، وزرار «المدير جاي!» بيقلب الشاشة جدول أرقام.

المرحلة دي (1) شغالة كلها على جهاز الزائر من غير سيرفر. النتايج بتتحفظ في المتصفح بتاعه.

## الملفات

```
render.yaml              إعدادات النشر على Render
public/                  الموقع نفسه (ده اللي بيتنشر)
  index.html
  css/style.css          التصميم كله
  js/data.js             الأسئلة والمعلومات وجمل الكتابة والإيميلات والدرجات
  js/core.js             الحفظ، النقط، الأصوات، زرار المدير، كارت الحضور
  js/games.js            الألعاب الخمسة
  js/learn.js            الأسئلة وتحدي النهارده
  js/share.js            كارت الشير ولينكات التحدي
  js/app.js              الصفحات والتنقل
  og.png                 الصورة اللي بتظهر لما حد يشير اللينك
  favicon.svg, icon-512.png, manifest.webmanifest
```

## النشر على GitHub و Render

1. اعمل Repository جديد على GitHub (مثلاً `zehe2t`) وارفع فيه كل الملفات زي ما هي: `render.yaml` و`README.md` وفولدر `public`.
2. على Render: اختار **New** ثم **Blueprint**، ووصّل الـ Repository. Render هيقرا `render.yaml` ويعمل Static Site اسمه `zehe2t`.
   - أو لو عاوز تعملها يدوي: **New** ثم **Static Site**، وخلّي **Publish directory** = `public`، و**Build command** فاضي أو `echo ok`.
3. اللينك هيبقى `https://zehe2t.onrender.com`. لو الاسم ده محجوز، Render هيدّيك اسم قريب منه. ساعتها غيّر الرابط في مكانين:
   - `public/js/share.js` في السطر `Z.SITE = { ... url: "..." }`
   - `public/index.html` في `og:url` و`og:image`
4. أي تعديل ترفعه على GitHub بيتنشر لوحده.

## إضافة محتوى

كل المحتوى في `public/js/data.js`:

- **سؤال جديد**: ضيفه في القسم المناسب بالشكل ده:
  ```js
  { q: "السؤال؟", o: ["اختيار 1", "اختيار 2", "اختيار 3", "اختيار 4"], a: 1, f: "المعلومة اللي بتظهر بعد الإجابة." }
  ```
  `a` هو رقم الإجابة الصح، والعد بيبدأ من 0. الاختيارات بتتلخبط لوحدها وقت اللعب.
- **قسم جديد**: ضيفه في `Z.CATEGORIES` وضيف أسئلته في `Z.QUESTIONS` بنفس الـ `id`.
- **جمل لعبة الكتابة**: `Z.PHRASES`.
- **إيميلات لعبة الإيميلات**: `Z.EMAILS.good` و`Z.EMAILS.bad`.

تحدي النهارده بيختار 5 أسئلة من كل الأقسام حسب التاريخ، فكل ما الأسئلة تزيد التحدي بيتكرر أقل.

## المرحلة 2 (السيرفر)

كل اللي محتاج سيرفر متجمّع في `Z.api` جوه `public/js/core.js`:

```js
Z.api = {
  online: false,
  async hit() {},                       // عداد الزوار
  async submitScore(gameId, score) {},  // تسجيل السكور
  async leaderboard(gameId, period) {}  // الترتيب العام
};
```

لما نوصّل قاعدة بيانات (Firebase أو سيرفر Node على Render) هنكتب الدوال دي بس. عداد «النهارده X زهقان دخلوا» موجود في الشريط العلوي ومستخبي لحد ما `hit()` يرجّع أرقام.

## اختصارات

- `Esc`: المدير جاي (ونفس الزرار يرجّعك). على الموبايل: اضغط مرتين على الشاشة.
- `1` لـ `4`: الإجابة في الأسئلة، و`Enter` للي بعده.
- `←` `→`: التحرك في «اهرب من الاجتماع».
