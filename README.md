# لو زهقت في الشغل ادخل هنا

موقع ألعاب ومعلومات تفاعلي باللغة العربية. النسخة الحالية تعمل داخل متصفح الزائر وتحفظ التقدم محليًا على جهازه، ولا تحتاج إلى خادم أو أمر بناء.

## رابط الموقع

بعد تفعيل GitHub Pages واكتمال أول عملية نشر، سيكون الرابط:

https://mahmoudallam100-rgb.github.io/zehe2t/

## نشر الموقع على GitHub Pages

تم إعداد المشروع لهذا المستودع: `https://github.com/mahmoudallam100-rgb/zehe2t`.

1. ارفع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على مجلدي `.github` و`public`. لا ترفع المجلد الخارجي الذي يحتوي المشروع كله؛ ارفع محتوياته.
2. افتح **Settings → Pages** في المستودع.
3. من **Build and deployment → Source** اختر **GitHub Actions**.
4. افتح تبويب **Actions** وتأكد أن مهمة **Deploy static site to GitHub Pages** انتهت بنجاح.
5. افتح الرابط أعلاه. قد يستغرق أول نشر بضع دقائق.

سير العمل موجود في `.github/workflows/deploy.yml`، ويرفع محتويات `public/` تلقائيًا عند كل push إلى `main` أو `master`، أو عند تشغيله يدويًا من Actions.

## محتويات المشروع

- `public/index.html` — صفحة الموقع والبيانات الوصفية للمشاركة.
- `public/css/style.css` — التنسيقات.
- `public/js/` — بيانات الألعاب والمنطق والتنقل والمشاركة.
- `public/og.png` — صورة معاينة المشاركة.
- `public/favicon.svg` و`public/icon-512.png` و`public/manifest.webmanifest` — الأيقونة وبيانات تطبيق الويب.
- `public/.nojekyll` — تعطيل معالجة Jekyll.
- `.github/workflows/deploy.yml` — النشر التلقائي إلى GitHub Pages.

## إضافة محتوى

المحتوى موجود في `public/js/data.js`:

- لإضافة سؤال، أضف عنصرًا بالشكل التالي:
  ```js
  { q: "السؤال؟", o: ["اختيار 1", "اختيار 2", "اختيار 3", "اختيار 4"], a: 1, f: "المعلومة بعد الإجابة." }
  ```
- قيمة `a` هي فهرس الإجابة الصحيحة ويبدأ العد من صفر.
- الجمل المستخدمة في لعبة الكتابة موجودة في `Z.PHRASES`.
- رسائل لعبة الإيميلات موجودة في `Z.EMAILS.good` و`Z.EMAILS.bad`.

## حدود النسخة الحالية

- لا يوجد backend؛ التقدم والنتائج محفوظة على جهاز كل زائر فقط.
- لا يوجد ترتيب عام مشترك أو عداد زوار فعلي.
- ملف `render.yaml` الخاص بالاستضافة القديمة على Render ليس مستخدمًا في نشر GitHub Pages.

## اختصارات لوحة المفاتيح

- `Esc`: تفعيل/إغلاق شاشة «المدير جاي!».
- `1` إلى `4`: الإجابة في الاختبارات، و`Enter` للمتابعة.
- `←` و`→`: التحرك في لعبة «اهرب من الاجتماع».
