# لو زهقت في الشغل ادخل هنا

موقع ألعاب ومعلومات للناس الزهقانة في الشغل: 5 ألعاب سريعة، 6 أقسام معلومات فيها اختبارات، تحدي يومي واحد لكل الناس، كارت شير «مذكرة داخلية» بالسكور، لينكات تحدي، وزرار «المدير جاي!» بيقلب الشاشة جدول أرقام.

**الرابط:** https://mahmoudallam100-rgb.github.io/zehe2t/

النسخة دي شغالة كلها على جهاز الزائر من غير سيرفر، ونتايج كل واحد محفوظة في المتصفح بتاعه.

## النشر

الموقع منشور على GitHub Pages من فرع `main` من جذر الريبو، يعني الإعداد في **Settings ← Pages** هو **Deploy from a branch** و `main` و `/ (root)`.

أي تعديل يترفع على `main` بيتنشر لوحده خلال دقيقة أو اتنين. وتقدر تتابع النشر من تبويب **Actions** تحت اسم «pages build and deployment».

## الملفات

```
index.html             الصفحة
css/style.css          التصميم كله
js/data.js             الأسئلة والمعلومات وجمل الكتابة والإيميلات والدرجات
js/core.js             الحفظ، النقط، الأصوات، زرار المدير، كارت الحضور
js/games.js            الألعاب الخمسة
js/learn.js            الأسئلة وتحدي النهارده
js/share.js            كارت الشير ولينكات التحدي (فيه رابط الموقع)
js/app.js              الصفحات والتنقل
og.png                 الصورة اللي بتظهر لما حد يشير اللينك
favicon.svg, icon-512.png, manifest.webmanifest
.nojekyll              بيخلّي GitHub ينشر الملفات زي ما هي
render.yaml            لو قررنا ننقل على Render بعدين
```

لو الرابط اتغير (دومين جديد مثلاً) غيّره في مكانين:
- `js/share.js` في السطر `Z.SITE = { ... url: "..." }`
- `index.html` في `og:url` و `og:image`

## إضافة محتوى

كل المحتوى في `js/data.js`:

- **سؤال جديد**: ضيفه في القسم المناسب بالشكل ده:
  ```js
  { q: "السؤال؟", o: ["اختيار 1", "اختيار 2", "اختيار 3", "اختيار 4"], a: 1, f: "المعلومة اللي بتظهر بعد الإجابة." }
  ```
  `a` هو رقم الإجابة الصح، والعد بيبدأ من 0. الاختيارات بتتلخبط لوحدها وقت اللعب.
- **قسم جديد**: ضيفه في `Z.CATEGORIES` وضيف أسئلته في `Z.QUESTIONS` بنفس الـ `id`.
- **جمل لعبة الكتابة**: `Z.PHRASES`.
- **إيميلات لعبة الإيميلات**: `Z.EMAILS.good` و `Z.EMAILS.bad`.

تحدي النهارده بيختار 5 أسئلة من كل الأقسام حسب التاريخ، فكل ما الأسئلة تزيد، التحدي بيتكرر أقل.

## المرحلة 2 (السيرفر)

كل حاجة محتاجة سيرفر متجمّعة في `Z.api` جوه `js/core.js`:

```js
Z.api = {
  online: false,
  async hit() {},                       // عداد الزوار
  async submitScore(gameId, score) {},  // تسجيل السكور
  async leaderboard(gameId, period) {}  // الترتيب العام
};
```

لما نوصّل قاعدة بيانات (Firebase مثلاً) هنكتب الدوال دي بس، وباقي الموقع مش هيتغير. عداد «النهارده X زهقان دخلوا» موجود في الشريط العلوي ومستخبي لحد ما `hit()` ترجّع أرقام.

## اختصارات

- `Esc`: المدير جاي، ونفس الزرار بيرجّعك. على الموبايل اضغط مرتين على الشاشة عشان ترجع.
- `1` لـ `4`: الإجابة في الأسئلة، و `Enter` للسؤال اللي بعده.
- `←` `→`: التحرك في «اهرب من الاجتماع».
